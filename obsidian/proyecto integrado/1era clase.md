Nombre del Proyecto: Sistema de Gestión de Inventario para Insumos Clínicos Descripción General Una institución de salud requiere implementar un sistema informático que permita administrar de manera eficiente el inventario de insumos clínicos, asegurando la disponibilidad de productos, el control de vencimientos y la optimización del proceso de abastecimiento. El sistema deberá proporcionar información actualizada en tiempo real sobre el stock existente y generar alertas para apoyar la toma de decisiones. Objetivo General Desarrollar un sistema de inventario que permita gestionar y controlar de forma eficiente los insumos clínicos, garantizando la disponibilidad de productos, reduciendo pérdidas por vencimiento y mejorando la planificación de compras. Objetivos Específicos 1. Registrar y mantener actualizado el stock de insumos clínicos. 2. Controlar las entradas y salidas de productos en tiempo real. 3. Configurar niveles mínimos de stock para cada producto. 4. Gestionar las fechas de vencimiento de los insumos almacenados. 5. Generar alertas automáticas por bajo stock y vencimientos próximos. 6. Facilitar la generación de órdenes de compra para reposición de productos. 7. Mantener un historial completo de movimientos realizados en el inventario. 8. Proporcionar información confiable para la toma de decisiones administrativas. Alcance del Sistema El sistema deberá permitir: • Registrar productos e insumos clínicos. • Realizar ingresos y egresos de inventario. • Consultar existencias disponibles. • Gestionar fechas de vencimiento. • Emitir alertas automáticas. • Generar órdenes de compra. • Mantener trazabilidad de los movimientos realizados. Requerimientos Funcionales RF01 - Gestión de Productos El sistema deberá permitir registrar, modificar, consultar y desactivar productos del inventario. RF02 - Control de Stock El sistema deberá actualizar automáticamente las existencias cada vez que se registre una entrada o salida de productos. RF03 - Stock Mínimo El sistema deberá permitir definir un stock mínimo para cada producto y monitorear su cumplimiento. RF04 - Registro de Vencimientos El sistema deberá almacenar y controlar la fecha de vencimiento de cada lote de productos. RF05 - Alertas de Bajo Stock El sistema deberá generar alertas cuando la cantidad disponible de un producto sea inferior al stock mínimo definido. RF06 - Alertas de Vencimiento El sistema deberá notificar cuando un producto esté próximo a vencer según un período configurable. RF07 - Órdenes de Compra El sistema deberá generar órdenes de compra editables para reposición de productos necesarios. RF08 - Historial de Movimientos El sistema deberá registrar todas las operaciones realizadas sobre el inventario, incluyendo ingresos, salidas, ajustes y anulaciones. RF09 - Consultas y Reportes El sistema deberá permitir consultar: • Stock actual. • Productos bajo stock mínimo. • Productos próximos a vencer. • Historial de movimientos. • Órdenes de compra emitidas. Requerimientos No Funcionales RNF01 - Seguridad El acceso al sistema deberá realizarse mediante autenticación de usuarios. RNF02 - Disponibilidad El sistema deberá estar disponible durante el horario operativo de la institución. RNF03 - Usabilidad La interfaz deberá ser intuitiva y fácil de utilizar por personal administrativo y clínico. RNF04 - Rendimiento Las consultas de inventario deberán responder en menos de 3 segundos. RNF05 - Integridad de Datos Toda transacción deberá registrarse garantizando la consistencia y auditoria de la información.
